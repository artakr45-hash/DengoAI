# Разработка DENGO AI STUDIO

## Локальный поиск по канону

`canon_guard.py` индексирует структурированные `.txt`-файлы в `data/knowledge/canon`, кроме `README_RU.txt`, который описывает правила работы с корпусом, а не факты мира. Каждый извлечённый фрагмент хранит категорию, сущность, статус и исходный файл с точными строками. Поддерживаемые категории: персонажи, государства, чудовища, печати, история и устройство мира.

Обычный `POST /chat` ищет только утверждённые фрагменты `[КАНОН]`. Для конкретных персонажей используется секция персонажа; при неоднозначном коротком имени (например, «Рен») API просит уточнение. Перечисленные параметры обрабатываются отдельно. Если параметр не обнаружен, ответ помечает его как `Не найдено поиском` и не утверждает, что данных нет во всём каноне.

Состояния поиска различаются: `FOUND`, `NOT_FOUND_BY_SEARCH` и `ABSENT_AFTER_REVIEW`. Последнее допустимо только при явно заданном полном охвате проверки. Текущий файловый индекс не охватывает PDF, поэтому отсутствие сведений во всех исходных материалах сейчас подтвердить нельзя.

Для просмотра рабочих сведений используйте отдельный маршрут `GET /review?status=...` со значением статуса: `ПРЕДЛОЖЕНИЕ`, `НЕ РЕШЕНО`, `СВЕРИТЬ`, `НЕОПРЕДЕЛЁН` или `БЕЗ СТАТУСА`. Маршрут возвращает только выбранный статус, исходный файл, номера строк и текст фрагмента. Эти сведения не подмешиваются в `POST /chat`.

Локальные оговорки вроде «требует сверки» выделяются в самостоятельный фрагмент со статусом `СВЕРИТЬ`, даже если находятся внутри блока `[КАНОН]`. Неизвестные и конфликтующие метки остаются в карантине.

## Запуск

Новые модели, платные инструменты и дополнительные пакеты не требуются. Ollama не используется.

```powershell
.venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8000
```

## Проверки

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты используют стандартный `unittest` и проверяют поиск, разметку статусов, provenance строк, неизвестные параметры, запрос уточнения имени и разделение маршрутов канона и рабочих сведений.
